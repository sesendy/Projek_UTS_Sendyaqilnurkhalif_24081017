## Fitur Aplikasi
- **Perhitungan Gaji (GajiActivity)**: Menghitung rincian gaji karyawan berdasarkan golongan, jabatan, status, dan tunjangan.
- **Petunjuk Penggunaan (PetunjukActivity)**: Panduan penggunaan aplikasi.
- **Tentang Aplikasi (TentangActivity)**: Informasi pengembang dan versi aplikasi.
